# 🎯 لعبة تخمين الرقم | Guess the Number Game

لعبة بسيطة بلغة Python — الحاسوب يختار رقم عشوائي بين 1 و 100،
وأنت تحاول تخمنه خلال عدد محدد من المحاولات.

هذا أول مشروع برمجي لي، سويته وأنا أتعلم أساسيات Python.

## 🎮 كيف تلعب

1. شغّل الملف
2. خمّن رقم بين 1 و 100
3. اللعبة تقولك إذا رقمك الصحيح أكبر أو أصغر من رقمها
4. عندك 7 محاولات تخمن فيها الرقم الصحيح

## 🛠️ التقنيات المستخدمة

- Python 3
- مكتبة `random` (لتوليد الرقم العشوائي)

## ▶️ كيف تشغلها

```bash
python3 guess_game.py
```

## 📚 شنو تعلمت من هذا المشروع

- المتغيرات (Variables)
- الحلقات (Loops) — تحديداً `while`
- الشروط (Conditionals) — `if / elif / else`
- التعامل مع مدخلات المستخدم (`input()`)
- معالجة الأخطاء (`try / except`)
- مكتبة `random` لتوليد أرقام عشوائية
